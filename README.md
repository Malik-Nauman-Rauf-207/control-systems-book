# 🤖 Feedback, Loops & Learning: Interactive Labs

Welcome to the official code repository for the book **Feedback, Loops & Learning: A Kid's Guide to Control Systems and Intelligence**. 

This repository contains all the interactive Python simulations used in the book. You don't need to install *anything* on your computer to run these—they all run instantly in your web browser using Google Colab!

## 🚀 How to Use These Labs

If you are reading the paperback version of the book, you can scan the QR codes at the end of each chapter, or click the links below.

1. Click the **Open in Colab** badge next to the chapter you want to play with.
2. A new tab will open in Google Colab (a free, secure Google service).
3. Click the "Play" `[ ▶ ]` button next to any block of code to run it!
4. **Want to experiment?** Change the numbers in the code and run it again to see what happens. (Don't worry, you can't break the master file. You are playing in your own private sandbox!)

## 👨‍🏫 For Parents and Teachers

These notebooks are designed for **ages 10–13**. They are completely safe and execute in Google's cloud servers, meaning no software needs to be downloaded to your local machine or school Chromebooks. 

Each notebook acts as a digital worksheet: it contains a mix of text explanations and isolated Python functions. Students are encouraged to change variables (like adding more delay to a sensor) to see how the system reacts.
